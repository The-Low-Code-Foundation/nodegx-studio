Publish to a server of your own

The app, its data and its cloud functions go to a Linux server you own, over ssh. Ship again with the same name to update it; its data stays.

As user@host, or a Host name from your ~/.ssh/config. It must already accept this computer’s ssh key: Studio cannot type a password.
A name whose DNS points at the server: it is served over https. Without one the app answers on the server only.
