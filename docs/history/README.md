# How NodeGX Studio started

These are the working papers of NodeGX phase 123 (2026-10-16/17), copied from the NodeGX repo's
`dev-docs/tasks/phase-123-open-bubble/` when the project moved here. They were written under the working title
"Open Bubble", dropped on 2026-10-19 because Bubble's brand guidelines forbid the BUBBLE name in another product's
name. They are kept as written: the brief in Richard's words, the look, the first play test, and the phase's README
with every ruling and finding. The plan of record is [../SCOPE.md](../SCOPE.md).
